## ostack (private)
A personalized slash-command framework on top of Claude Code. Seven modes
that encode my operating practices and keep Claude in the right mental
stance for each stage of product work:

- /discover — Teresa Torres Continuous Discovery / OST framing
- /define — Amazon Working Backwards (press release first)
- /delete — Musk's 5-step process, step 1 (question requirements) and 2 (delete)
- /architect — systems design mode
- /board — simulated advisory board (Musk, Thiel, Ive, Amodei, Hassabis, Huang, Jobs)
- /review — structured critique mode
- /ship — execution and rollout checklist

The commands themselves are private because they encode personal operating
patterns refined over multiple years. The framework is shared here to
document how I think about working with AI tools.
